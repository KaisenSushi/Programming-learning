# Project: Publish a Small Python Repository

[Module home](README.md) | [Exercises](exercises.md) | [Solutions](solutions.md) | [Roadmap](../ROADMAP.md)

Create a repository named `practice-counter`. Its Python program should accept a line of text and report the number of characters and words. Include a `README.md` with a plain-language purpose, Python requirement, run command, and example. Add a `.gitignore` for `__pycache__/` and `.venv/`.

Make the initial structure on your main branch and commit it. Then create a branch named `add-nonempty-count`. On that branch, change the program so blank input reports a clear message instead of ordinary counts. Update the README example and manually test both blank and nonblank input. Commit the related code and documentation together.

Create an empty GitHub repository and connect it as `origin`, following the lesson and substituting your actual URL. Push the main branch and feature branch. Open a pull request from `add-nonempty-count` into `main` with a summary and a test note. Review the changed files before merging.

Completion evidence should include a clean `git status`, a short decorated log, the remote URL with no embedded credentials, and the pull request link. If you do not have a GitHub account, stop after the local branch and merge workflow and record the exact remote steps you would take. Do not invent a published link.
