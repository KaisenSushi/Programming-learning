# Git and GitHub Quiz

[Module home](README.md) | [Exercises](exercises.md) | [Solutions](solutions.md) | [Roadmap](../ROADMAP.md)

Answer before checking a repository. Then verify command behavior in disposable practice work where necessary.

1. What does `git init` add to a project directory?
2. What are the working tree, staging area, and commit history used for?
3. Does `git add` upload a file to GitHub?
4. Which command shows changes that have not been staged?
5. Which command shows the content proposed for the next commit?
6. What does a branch name point to?
7. What should you inspect before using `git restore` on a changed file?
8. Why is `git revert` suitable for undoing a shared commit?
9. What is a Git remote?
10. Does setting `user.email` authenticate you to GitHub?
11. What does `git fetch` do differently from `git pull`?
12. What is the purpose of a pull request?

Award one point per correct answer. Ten correct answers shows a sound foundation. If you confuse staging, committing, and pushing, repeat the first exercise and narrate where each version of the file exists.
