# Quiz

[Module home](README.md) | [Solutions](solutions.md)

Answer with a short explanation rather than only a keyword.

1. What value does `main` conventionally return on success?
2. Why should an array parameter usually have a separate length parameter?
3. What does `const int *values` promise through that pointer?
4. Name three forms of undefined behavior involving memory.
5. Why must allocation-size multiplication be checked?
6. Does assigning `NULL` to one pointer repair other dangling aliases?
7. What byte marks the end of a C string?
8. Why is `gets` unsafe?
9. What is the usual difference between a compiler error and an undefined-reference linker error?
10. What belongs in a header, and what usually belongs in a source file?
11. What does an include guard prevent?
12. Why are sanitizers helpful but insufficient?

The [solutions](solutions.md) provide concise answer notes and a project design outline.
