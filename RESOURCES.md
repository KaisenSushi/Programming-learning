# Resources

Use these links when a lesson introduces a tool or when you need a reference after finishing a chapter. Official documentation is the best place to confirm current behavior. Tutorials can help with the first explanation, but documentation should settle questions about syntax, commands, and supported features.

For a command-by-command Windows installation, use [Windows setup](SETUP-WINDOWS.md). For lectures and demonstrations, use [Videos](VIDEOS.md).

## Setup and general references

- [Visual Studio Code documentation](https://code.visualstudio.com/docs)
- [MDN command line crash course](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Environment_setup/Command_line)
- [Microsoft Windows Terminal documentation](https://learn.microsoft.com/en-us/windows/terminal/)
- [GNU Bash manual](https://www.gnu.org/software/bash/manual/)

## Algorithms and computer science

- [VisuAlgo](https://visualgo.net/en)
- [Open Data Structures](https://opendatastructures.org/)

- [MDN beginner learning path](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started)

These resources may use different notation or languages. Translate examples into Python and test them with small inputs. Translation is a useful check that you understood the idea rather than memorized a page.

## SQL and databases

- [SQLite documentation](https://www.sqlite.org/docs.html)
- [PostgreSQL tutorial](https://www.postgresql.org/docs/current/tutorial.html)
- [SQLBolt interactive lessons](https://sqlbolt.com/)

SQL dialects differ. The course uses broadly supported SQL and points out SQLite-specific behavior where it matters. Check the manual for the database you use in production.

## C and systems

- [C language reference](https://en.cppreference.com/w/c)
- [GCC manuals](https://gcc.gnu.org/onlinedocs/)
- [Clang documentation](https://clang.llvm.org/docs/)
- [GDB documentation](https://sourceware.org/gdb/documentation/)
- [Valgrind documentation](https://valgrind.org/docs/manual/manual.html)

Compiler warnings deserve attention. Build course programs with a modern language mode and strong warnings, then fix the cause of each warning rather than hiding it.

## Practice

- [Exercism](https://exercism.org/)
- [Advent of Code](https://adventofcode.com/)
- [Project Euler](https://projecteuler.net/)

Practice sites are supplements. Keep building the course projects because a program with several interacting parts teaches design, testing, and revision in a way that isolated puzzles cannot.
