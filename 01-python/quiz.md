# Python Quiz

[Module home](README.md) | [Exercises](exercises.md) | [Solutions](solutions.md) | [Roadmap](../ROADMAP.md)

Answer from memory, then use the interpreter to check the parts you missed. Each question has one intended core answer.

1. What type does `input()` return?
2. What value does `7 // 3` produce?
3. What value does `7 % 3` produce?
4. In an `if` and `elif` chain, how many branches can run during one evaluation?
5. What integers are produced by `range(3)`?
6. Which loop is usually clearer when visiting every item in a known list?
7. What is the purpose of `return` in a function?
8. Which collection best represents unique tags when order does not matter?
9. Which collection best maps a username to a score?
10. Why should an average function check for an empty collection?
11. Do Python type hints automatically reject values of the wrong type at runtime?
12. Why is catching every possible exception around a whole program risky?

Award one point for each correct answer. Ten correct answers is a solid result. Revisit functions and collection choice if you cannot explain your answer without relying on the wording of the question.
