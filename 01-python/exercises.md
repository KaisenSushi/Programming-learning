# Python Exercises

[Module home](README.md) | [Lessons](01-values-and-input.md) | [Solutions](solutions.md) | [Roadmap](../ROADMAP.md)

Write each answer as a small Python program or function. Test at least one normal case and one boundary case. Keep input and printing outside calculation functions unless an exercise explicitly asks for interaction.

1. Convert a temperature in Celsius to Fahrenheit using `fahrenheit = celsius * 9 / 5 + 32`. Accept text input, convert it, and display one decimal place.
2. Write `classify_score(score)` that returns `"invalid"` outside 0 through 100, `"pass"` for 60 or more, and `"retry"` otherwise.
3. Use a loop to sum only the positive values in `[-2, 5, 0, 8, -1]` without calling `sum`.
4. Write `count_words(words)` that returns a dictionary mapping each word to its frequency. Treat the supplied strings exactly as given.
5. Write `average(values)` that raises `ValueError` for an empty list and otherwise returns the arithmetic mean.
6. Ask repeatedly for a positive whole number until the user enters one. Print a clear correction message after invalid input.
7. Given a list of topic names containing duplicates, produce a sorted list of unique names.
8. Explain why a function that returns a result is generally easier to reuse and test than one that only prints it.

When you finish, alter inputs to include an empty string, zero, negative values, and repeated words where those cases apply.
