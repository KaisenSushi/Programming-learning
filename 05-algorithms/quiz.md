# Quiz

[Module home](README.md) | [Exercises](exercises.md) | [Project](project.md) | [Solutions](solutions.md)

Answer in your own words. Include a small example where it helps.

1. Why can binary search discard half of its remaining input?
2. What input requirement must hold before ordinary binary search is valid?
3. What are the worst-case time costs of linear search and binary search?
4. Why might sorting before one search be more work than a direct scan?
5. What does a stable sorting algorithm preserve?
6. Which structure does BFS use, and what exploration pattern results?
7. Which structure does iterative DFS use?
8. Why is a visited set necessary in a graph with cycles?
9. What does BFS guarantee about paths in an unweighted graph?
10. What two problem properties suggest dynamic programming?
11. In a dynamic programming design, what are a state, a base case, and a transition?
12. Why does the iterative Fibonacci function need only constant extra space?

Use [solutions.md](solutions.md) to check your reasoning. If your wording differs but expresses the same precise idea, it can still be correct.
