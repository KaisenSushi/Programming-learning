# Data Structures

[Roadmap](../ROADMAP.md) | [Start lesson 1](01-sequences-and-mappings.md)

A data structure is a way to organize values. The choice matters because it changes which jobs are simple or fast.

For example, a list keeps items in order. A dictionary finds a value by its key. A stack gives you the newest item first. A queue gives you the oldest waiting item first.

Draw the data on paper before and after each change. This is often easier than trying to hold every value in your head.

You are done when you can choose a structure based on the work you need to do. You should be able to explain the choice in plain English, not only name the structure.

The [CS50 course site](https://cs50.harvard.edu/x/) has optional visual lessons on linked lists, trees, and hash tables.
