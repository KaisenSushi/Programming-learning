# Quiz

[Module home](README.md) | [Solutions](solutions.md)

Answer each question in one or two clear sentences.

1. What gives a stored sequence of bits meaning?
2. Why is hexadecimal convenient for programmers?
3. How many unsigned values can eight bits represent, and what range is that?
4. Why is a character not always one byte in UTF-8?
5. What are the four steps in the simplified instruction cycle?
6. What is an instruction set architecture?
7. Order registers, cache, RAM, and persistent storage by typical access speed.
8. What does virtual memory provide to a process?
9. Why can unsynchronized shared data be wrong even on a fast multicore CPU?
10. What job does a linker perform?
11. What does the operating system loader do?
12. How can debug information help a debugger?

The [solutions](solutions.md) provide a concise answer key and project guidance.
