# Computer Architecture

Computer architecture explains what happens below source code. You do not need electrical-engineering experience for this module. We will connect familiar values and programs to bits, processor instructions, memory, and compiled files. The aim is a useful mental model, not memorizing every part of a modern processor.

Read [Bits and Data](01-binary-data.md), [CPU and Memory](02-cpu-memory.md), and [From Source to Execution](03-compilation-execution.md). Then complete the [exercises](exercises.md), [quiz](quiz.md), and [project](project.md). Use [solutions](solutions.md) after attempting the work.

By the end, you should be able to convert small binary values, explain how a CPU follows instructions, distinguish registers, cache, RAM, and storage, and describe how source becomes a running process. Return to the [course roadmap](../ROADMAP.md) when you want the wider course path.

Optional video: [Nand2Tetris Part I](https://www.nand2tetris.org/course) provides university-level videos and projects that build a computer from simple logic. The first units are useful after this module, but the course is optional and more detailed.
