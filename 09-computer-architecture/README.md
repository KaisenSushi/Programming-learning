# Computer Architecture

[Roadmap](../ROADMAP.md) | [Start lesson 1](01-binary-data.md)

This module explains what happens below your source code. It connects the programs you already wrote to bits, processor instructions, memory, and executable files.

You do not need an electronics background. The goal is a useful picture of the whole path, not a list of processor parts to memorize.

## Do these in order

1. [Bits and data](01-binary-data.md)
2. [CPU and memory](02-cpu-memory.md)
3. [From source to execution](03-compilation-execution.md)
4. [Exercises](exercises.md)
5. [Quiz](quiz.md)
6. [Project](project.md)
7. [Solutions](solutions.md)

Draw simple diagrams as you work. Show where an instruction or value moves next. The real hardware is more complex, but the small model gives you a base you can improve later.

You are done when you can read a small binary number, explain the basic job of a CPU, tell the difference between registers, cache, RAM, and storage, and describe how source code becomes a running process.

[Nand2Tetris Part I](https://www.nand2tetris.org/course) has optional videos and projects if you want to go deeper.
