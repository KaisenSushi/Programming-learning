# Exercises

[Module home](README.md) | [Solutions](solutions.md)

Show your working instead of writing only final values.

1. Convert decimal 13, 42, and 255 to eight-bit binary. Convert binary `00110110` to decimal.
2. Convert binary `10101111` to hexadecimal, and convert hexadecimal `3C` to binary.
3. State how many distinct values fit in 4, 8, and 16 unsigned bits. Explain the general rule.
4. Encode the plain ASCII letters `C`, `P`, and `U` as decimal bytes using an ASCII table. Explain why this exercise does not prove every visible character occupies one byte.
5. Put registers, cache, RAM, and SSD storage in a typical order from fastest and smallest to slowest and largest. State why the words typical and approximate matter.
6. Draw the simple fetch, decode, execute cycle and add one branch back to fetch.
7. Classify each failure by stage: invalid C syntax, unresolved function definition, missing shared library at startup, and division by zero while running.
8. Explain why an x86-64 executable generally cannot run natively on an AArch64 processor.

Review [solutions](solutions.md) after attempting every conversion and explanation.
