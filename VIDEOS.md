# Video guide

Videos are optional. Use one when a diagram, live demonstration, or second explanation helps. Pause often, type the examples, and return to the course exercises afterward. Watching a long lecture without doing the work can feel productive while leaving the main skill untested.

## Start with programming

- [CS50x 2026 Python lecture on YouTube](https://www.youtube.com/watch?v=Rl0ludWTLxs) covers functions, data types, conditions, loops, exceptions, lists, dictionaries, files, and packages. It is a useful second explanation during the [Python module](01-python/README.md). The lecture moves quickly, so split it across several study sessions.
- [Harvard CS50x course page](https://cs50.harvard.edu/x/2026/) organizes full lectures, shorter topic videos, sections, and problem sets. Use it for a broad computer science view. This repository keeps a gentler order by teaching Python before C.

## Git and GitHub

- [Git and GitHub for Beginners on YouTube](https://www.youtube.com/watch?v=RGOj5yH7evk) demonstrates repositories, commits, branches, and remote work. Watch the matching section after reading the [Git and GitHub module](02-git-github/README.md), then repeat the commands in a disposable practice repository.
- [GitHub Skills](https://skills.github.com/) offers short interactive exercises inside real repositories. Start with the introduction course once you can make a local commit.

## Data structures and algorithms

- [MIT 6.006 algorithm lecture videos](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/resources/lecture-videos/) cover dynamic arrays, sorting, hashing, trees, graph search, shortest paths, and dynamic programming. These are university lectures. Read this course's simpler [Data structures](04-data-structures/README.md) and [Algorithms](05-algorithms/README.md) chapters first.
- [MIT 6.006 Lecture 1 on YouTube](https://www.youtube.com/watch?v=ZA-tUyM_y7s) introduces algorithms and computation. Focus on how the instructors define a problem, a correct output, and an efficient procedure.

## Memory, C, and databases

- [CS50x 2026 Memory lecture on YouTube](https://www.youtube.com/watch?v=db0H0U13YsA) uses C to make addresses, pointers, allocation, and common memory mistakes visible. Pair it with the [C module](08-c/README.md). Do not copy memory-management code without understanding who owns each allocation.
- [CS50x 2026 SQL lecture on YouTube](https://www.youtube.com/watch?v=oqRU2So6Z2Y) demonstrates relational data and queries. Watch it during the [SQL and databases module](07-sql-databases/README.md), then write the queries yourself against a small SQLite database.

## How to use a video well

1. Write down the topic you want the video to clarify.
2. Watch ten to twenty minutes at a time.
3. Pause before code runs and predict the result.
4. Recreate the example without copying from the screen.
5. Change one input or rule and explain the new result.
6. Return to the related exercise or project.

If a video and the current official documentation disagree about a command or supported version, follow the current documentation. Videos age faster than reference pages.
