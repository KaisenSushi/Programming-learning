# Code of Conduct

## Our standard

This project is a place to learn in public. Contributors and learners are expected to be patient, specific, and respectful. People arrive with different experience, language backgrounds, equipment, and amounts of time.

Helpful behavior includes:

- explaining technical disagreement with evidence or a reproducible example
- asking questions without mocking someone for missing context
- accepting corrections and updating earlier claims
- giving feedback about the work rather than the person
- making room for new contributors to participate
- protecting private information shared by mistake

Unacceptable behavior includes harassment, threats, discrimination, sexualized attention, personal attacks, deliberate disruption, or publishing another person's private information. Repeatedly dismissing sincere beginner questions or using review as a way to belittle someone is also unacceptable.

## Scope

These expectations apply in repository issues, pull requests, discussions, and other public spaces used for this project. They also apply when someone officially represents the project elsewhere.

## Reporting

Report harmful behavior privately to the repository owner through a contact method listed on the owner's GitHub profile. Do not open a public issue containing sensitive details. Include links, dates, and a short description of what happened when it is safe to do so.

The maintainer will review reports in good faith, protect the privacy and safety of the reporter as far as possible, and choose a response that fits the situation. Responses may include a clarification, warning, removal of content, temporary restriction, or permanent ban.

## Enforcement

Maintainers may edit or remove contributions that do not follow this code. They may also limit participation when behavior makes the project unsafe or prevents useful collaboration. Decisions should be explained to the affected person unless doing so would create more risk.

This code is adapted from the principles of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), with wording kept specific to this learning project.
