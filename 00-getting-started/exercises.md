# Getting Started Exercises

[Module home](README.md) | [Lessons](01-how-computers-run-programs.md) | [Solutions](solutions.md) | [Roadmap](../ROADMAP.md)

Complete these tasks in a disposable practice directory. Write down the command you used and the result you observed. If a command fails, keep the error long enough to explain the cause before correcting it.

1. Explain in your own words how source code, a language implementation, a process, and the operating system participate when a Python file runs.
2. Check your Python version. Then identify the path of the Python executable found by your shell.
3. Create a directory named `terminal-practice` and move into it. Confirm the current location before continuing.
4. Create `observation.txt` containing one sentence. Read it from the terminal, append a second sentence, and read the final contents.
5. Create `where_am_i.py` that prints both `Path.cwd()` and the resolved path of `__file__`. Run it from its own directory, then move to its parent and run it using a relative path. Explain which value changes.
6. Intentionally run Python with a misspelled filename. Record whether the failure happened in the shell, Python startup, syntax checking, or program logic, and justify your answer.
7. Give one example each of a syntax error, runtime error, and logic error. You may use short Python snippets.

Do not copy commands blindly between shell families. Translate the operation into syntax appropriate for your terminal.
