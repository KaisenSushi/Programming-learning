# Getting Started Quiz

[Module home](README.md) | [Exercises](exercises.md) | [Solutions](solutions.md) | [Roadmap](../ROADMAP.md)

Answer without running commands first. Then verify any answers you are uncertain about in a disposable directory.

1. What is the difference between source code and machine instructions?
2. What operating system object is created when a program starts running?
3. Which kind of storage normally retains a source file after power is turned off: RAM or persistent storage?
4. What does a shell do when you enter a program name?
5. If the current directory is `course/module`, what location does `..` represent?
6. Why should a path containing spaces usually be quoted in a command?
7. What is the conventional meaning of a process exit status of zero?
8. A valid program divides a total by zero while running. Is this most likely a syntax, runtime, or logic error?
9. A program runs successfully but calculates tax with the wrong percentage. What category of error is this?
10. Why might `Path.cwd()` differ from the directory containing the Python script?

Score one point per answer. Eight or more correct answers suggests you are ready for the project. If you miss a question about paths or errors, revisit the corresponding lesson and test the idea directly.
